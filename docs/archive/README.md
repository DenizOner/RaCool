# Tarihsel belge arşivi

Bu dizindeki `*.before-document-separation.md` dosyaları, yönerge ve mimari belgelerinin günlük kayıtlarından ayrılmadan önceki birebir kopyalarıdır. Eski ara sonuçları ve teknik ayrıntıları kaybetmemek için korunurlar.

**Etkin yönerge, güncel mimari veya güncel görev listesi değildirler.** İçlerindeki bekleyen/tamamlanan ifadeler, komutlar ve önceki arayüzler bugünkü durum olarak kullanılmamalıdır. Güncel sözleşme için kaynak arayüzünü ve CODEBASE.md'yi; çalışma kanıtı için DEV_VERIFICATION_REPORT.md'yi; kalan iş için TASK_CHECKLIST.md'yi kullanın. Arşive yeni oturum kayıtları eklemeyin.
